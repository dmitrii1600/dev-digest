  - 4 of the 7 non-MET rows in 20-verify-1.md were stale plan text or disclosed deviations, not code gaps.
  - The implementer cannot edit the plan, so the coordinator amended the plan by hand ("Amended during build").
- **A known flake with a known fix lingered.**
  - `server/INSIGHTS.md` 2026-09-24 named the fix for `reviews.it`.
  - It stayed red through 22-verify-2, 25-tests and 42-verify-final.
  - It was fixed in 7 lines per file post-run, and the `.it` lane fell from ~71 s to ~37 s.
- **Gate friction:**
  - The static `test-naming` rule flags `import type { Db } from '../src/db/client.js'` as DB-backed (a CRITICAL).
  - It misses `startPg` from `test/helpers/pg.ts`, which produced 6 false WARNINGs.
  - Scratch files written to the `.devdigest/` root are not git-ignored, so they changed the fingerprint ("tree changed since `scope` ran").
  - Committing turns untracked files into tracked ones and also changes the fingerprint ("report is stale" on push), so the gate had to run twice.
- **The plan review was not cross-family.** It ran on Claude Fable 5.1, same family as the author, and the person accepted it. The course asks for another family. The prompt file existed (`cross-model-review-prompt.md`), but nothing in the chain names the requirement.
- **Measurement artefact.**
  - `retro-usage.mjs` counts `node scripts/verify.mjs …` executions as reads of `scripts/verify.mjs`: 70 "reads" by 14 readers.
  - That makes earlier proposal #7 (a flag table in AGENTS.md) look ineffective when it may not be.
